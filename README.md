# Unison Direct Management Reporting

Management reporting web application for **Unison Direct GCC INC**.

## Workflow

Upload Excel/CSV → Process financial data → Analytical dashboard → Edit imported data → Report preview → Download PDF.

## Features

- Client financial workbook upload
- Profit & Loss and Balance Sheet detection
- Analytical KPI dashboard
- Editable imported workbook data
- Management report preview
- UNISON DIRECT watermark
- PDF generation and download
- Required management-purpose disclaimer
- Responsive UI
- Vercel-ready static deployment

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

Import this GitHub repository into Vercel. The project is a static web application and includes `vercel.json`.

## Confidentiality

Financial information processed by this prototype remains in the user's browser unless a future backend/storage integration is explicitly added.
